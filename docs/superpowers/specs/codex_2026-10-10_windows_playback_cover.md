# Windows 当前播放封面

Yves 要求 Windows 和已完成的 Android 功能一致：读取本机播放器当前歌曲时，自动带入系统提供的专辑或播放器封面。按 Yves 的默认执行规则，直接实施最佳推荐方案。

## 范围与设计

- 继续使用既有 Windows SMTC 会话和网易云只读元数据补全。只读取正在播放且有标题的同一会话，通过 `getCurrentTrack({ includeArtwork: true })` 返回顶层 `coverDataUrl`；首页不请求图片。
- 从媒体属性的 `Thumbnail` 获取系统提供的流。输入最多 4 MiB、20,000,000 像素，输出最长边 512 像素、最多 1,000,000 字节 JPEG；有界等待、释放流和自建图片对象。图片缺失、坏图、超限或超时不影响歌曲元数据。
- 乐评和速记使用既有草稿及封面 SQLite 存储；新增可选 `coverFromPlayback` 草稿来源。保存正式记录才补齐封面；已有手动封面优先，自动写入只在无图时成功。作品身份改变、手动选图和较新读取使旧结果失效。
- 保持 JSON v6、数据库结构、应用身份、安装路径和个人数据目录。无图备份移除图片和自动来源标记。不做后台持续采集，不抓播放器窗口，不联网寻找封面。
- 两个独立项目仅移植必要封面逻辑；不全量同步 Android 文件、不改变签名申请的暂停状态。

## 验收

真实 Windows PowerShell/WinRT 读取按需图像；合成缩略图检查边界与降级；真实 Electron 独立 profile 验证乐评/速记预览、草稿恢复、SQLite 持久化、手动封面和身份竞态，无图仍可保存。未提供会话图片的播放器兼容性不能宣称通过。构建桌面资源并运行现有 Windows 回归，交付可运行便携包，不上传或发布。
