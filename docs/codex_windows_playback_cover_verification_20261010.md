## 实现与限制

- `NowPlaying.getCurrentTrack({ includeArtwork: true })` 按需返回顶层 `coverDataUrl`；原来的无参数读取仍不处理图片。
- 原生从同一媒体属性的 `Thumbnail` 读取，最多 4 MiB / 20 MP；输出最长边 512、最多 1,000,000 字节 JPEG；图片缺失、损坏、超限和读取超时不会隐藏歌曲。流、图片及绘图对象在 finally 中释放。
- 图片查询先保护现有封面；自动写入使用条件插入。播放图绑定作品身份和读取/选图 revision；来自存储的自动预览也绑定查询身份，修改后清除。草稿新增可选 `coverFromPlayback`，JSON v6 和数据库结构不变；无封面备份同时清除图片与来源。
- 酷狗实测把 `《NewJeans 2nd EP 'Get Up'》` / `《NewJeans 'OMG'》` 放入 `AlbumArtist`。只对已核实来源 `kugou` 的这种书名号格式忽略该字段，保留实际 `Artist`，不据该描述猜专辑。正常专辑歌手和其他来源保持原值。
- 系统媒体会话缩略图契约见 [微软 Thumbnail 文档](https://learn.microsoft.com/en-us/uwp/api/windows.media.control.globalsystemmediatransportcontrolssessionmediaproperties.thumbnail?view=winrt-28000)。抓取证据和失败搜索记录在 `.firecrawl/codex_windows_*_20261010.*`；原生类型/流兼容性另经本机 WinRT 验证。
