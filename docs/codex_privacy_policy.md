# 小懂哥 Windows 隐私说明

适用范围：本仓库 Windows 3.1.1 的实际行为；更新日期：2026-10-08。

## 本地数据

乐评、评分、封面、听歌情境和档案保存在 `%APPDATA%\xiaodongge-windows\archive\music_feelings_archive.sqlite`。草稿、主题和阅读偏好保存在同一应用数据目录中的 Chromium 存储。没有应用账号、云同步、广告或向发布者上传档案的功能。

用户选择备份或导出时，程序向所选位置写入文件。卸载安装版会保留个人档案和偏好；请自行管理这些文件及导出的备份。JSON 备份和截图可能含有私人内容，分享前请自行核对。

## 联网行为

| 服务 | 触发方式 | 发出的信息 |
| --- | --- | --- |
| Apple iTunes 音乐目录 | 打开记录或速记页面后读取当前播放；速记页重新可见、点击读取或切换到当前歌曲时也会进行补全 | 歌曲名、歌手、已有专辑名，以及 CN/US 目录地区；网络服务可看到连接 IP |
| Open-Meteo 城市搜索 | 用户搜索天气城市 | 搜索的城市名称；网络服务可看到连接 IP |
| Open-Meteo 历史天气 | 已选择城市后请求天气，或生成回顾时补取未缓存天气 | 已选城市经纬度、日期范围、时区及天气字段；网络服务可看到连接 IP |

这些请求直接连接第三方服务，不通过发布者服务器。音乐目录请求不发送乐评正文、评分、草稿、截图或整个数据库。天气请求不发送音乐标题或乐评正文。

第三方服务如何处理请求信息，以 [Apple 隐私政策](https://www.apple.com/legal/privacy/) 和 [Open-Meteo 隐私说明](https://open-meteo.com/en/terms#privacy) 为准。

3.1.1 没有独立的联网总开关或安装时禁用上述请求的选项。可以离线使用本地记录、备份和导出；联网补全不可用时保留本地结果，天气请求失败不会阻止本地回顾。不能把当前版本描述为仅在点击“读取”按钮时才联网。

## 本机系统功能

当前播放通过 Windows 系统媒体会话读取；网易云缺失信息的补全只读本机播放队列。截图 OCR 通过 Windows 原生接口在本机处理，临时识别图片在处理后移除。这些原生操作不把截图或本机队列发送给发布者；后续音乐目录补全按上表发送音乐名称。
